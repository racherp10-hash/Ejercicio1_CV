Proyecto Nova Online

Sistema de Gestión de Inventario

Descripción del Proyecto

Nova Online es un proyecto universitario desarrollado para gestionar productos, inventarios y movimientos de almacén.

Objetivo del Proyecto

Desarrollar un sistema que permita registrar productos, controlar inventarios y gestionar la entrada y salida de productos.

Tecnologías Utilizadas

  • Java
  • Python
  • C#
  • SQL Server
  • MySQL

Funciones del Sistema

  • Registro de productos
  • Modificación de productos
  • Control de inventarios
  • Registro de compras
  • Registro de entradas y salidas
