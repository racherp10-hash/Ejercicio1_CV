Proyecto LavaFácil

Sistema de Gestión de Lavandería

Descripción del Proyecto

LavaFácil es un proyecto desarrollado para gestionar la información de una lavandería, incluyendo clientes, pedidos, servicios y pagos.

Objetivo del Proyecto

Desarrollar un sistema que permita administrar los pedidos de los clientes, controlar los servicios de lavandería y registrar los pagos realizados.

Tecnologías Utilizadas

  • SQL Server 2022
  • SQL Server Management Studio
  • C#
  • ASP.NET Core
  • Database Mirroring

Funciones del Sistema

  • Registro de clientes
  • Gestión de pedidos
  • Administración de servicios
  • Registro de pagos
  • Consultas mediante procedimientos almacenados
  • Replicación de la base de datos mediante Mirroring

Mi Participación en el Proyecto

Participé en el desarrollo de procedimientos almacenados, consultas SQL y pruebas de la base de datos. También trabajé en la configuración del servidor espejo utilizando Database Mirroring.
